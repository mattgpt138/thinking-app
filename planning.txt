PHASE 1 — Initial build                                        [8bc08b2] DONE
--------------------------------------------------------------------------------
  Static PWA, vanilla JS, no build step, no framework, no npm.

  - Even 3-day rotation (argument, math, reasoning) driven by a cycle index
    that increments only on COMPLETED sessions, so skipping a day does not
    skip a type.
  - Session length ramps: 600s base, +60s every 6 completed sessions, cap 2400s.
  - SIGNATURE: the timer withholds its numeric readout until the final 60
    seconds and fills a thin arc instead. Deliberate. Not to be "fixed".
  - data/corpus.json: 53 passages, 24 works, 24 authors, fetched VERBATIM from
    Project Gutenberg via a scripted extraction harness (never transcribed by
    hand). 400-787 words each. Pre-1930 publication; pre-1930 translations only
    (Marriott, Cole, Long, Jowett, Burnet, Moore). 111 hand-written
    interrogation questions.
  - data/reasoning.json: 70 calibration statements (35 true / 35 false),
    17 Fermi prompts with reference decompositions.
  - Math: 8 locally generated levels, adaptive on a rolling window of 10.
  - Reasoning: calibration (Brier), Fermi, procedural base-rate problems.
  - Position file with full revision history.
  - Optional Anthropic API with an explicitly adversarial system prompt kept in
    one clearly marked, editable block. Degrades to bundled content; never
    blocks a session on the network.
  - localStorage only. Export/import JSON. Offline via service worker.

  Bugs found and fixed during build: parseMagnitude returned 0 for junk input;
  startReasoning was not awaited (race); an API-failure notice was written then
  immediately wiped.

PHASE 3 — Soft time limit and the review view                  [9c2a374] DONE
--------------------------------------------------------------------------------
  Reported: the session closed while the user was still typing, and there was
  no way back to anything written.

  - The limit is now SOFT. Time running out completes the arc, shows one quiet
    line, and swaps the foot button from Abandon to Close. It does not close
    the session, move focus, or touch the text being typed. A session counts as
    completed once the time has elapsed, however long you write past it.
  - New review tab: every session, finished or not. Opening an argument session
    restores the passage, every question and every answer, and offers to keep
    pressing with no clock on it.
  - Abandoning now keeps the transcript. It only means the session does not
    count towards the rotation.

PHASE 4 — Conversational interrogation, correct today tab      [fb1b036] DONE
--------------------------------------------------------------------------------
  Reported: the interrogation was not two-way; it generated a new prompt with
  no engagement. Also, the today tab showed tomorrow's assignment.

  Two causes for the first, both self-inflicted:
  - The PROMPT banned opening praise so hard it also banned engagement. It
    forbade characterising the response, summarising it back, and resolving
    anything, leaving a bare question. Replies must now ENGAGE with what was
    written, COUNTER with a real argument, and only then PRESS. Anti-flattery
    bans kept and sharpened. Engaging with a point is not complimenting it.
  - The FLOW skipped the API whenever the previous question came from the
    model, so every second turn was a canned bundled question. Bundled
    questions are now an opening move and a fallback pool; with a key, every
    answer gets a reply. The position challenge is held separately and given
    priority after the first exchange so a running conversation cannot crowd
    it out.
  - Requests now send a real alternating user/assistant thread rather than one
    flattened block.
  - Today tab: detects a completion on the current calendar day and shows that
    day's work as done, names what is next, and offers to reopen it.

PHASE 5 — Seven day types                                      [3306ef1] DONE
--------------------------------------------------------------------------------
  User removed the artificial constraint on rotation length and asked for more
  critical-thinking coverage. Nesting was the problem: a reasoning sub-mode
  came round only every nine days.

  Rotation: argument -> logic -> steelman -> math -> causal -> numbers ->
  calibration. Nothing nested. Weekly cycle.

  - LOGIC (new, generated, offline, 6 adaptive levels): conditional forms,
    contrapositive/converse/inverse, quantifier negation, categorical
    syllogisms, necessary vs sufficient, validity vs soundness and the Wason
    selection task. Terms drawn at random; predicates carry both verb forms.
  - CAUSAL (new, generated): confounding, selection effects, reverse causation,
    regression to the mean, Simpson's paradox with figures that work out.
    Scored choice plus a written follow-up whose reference stays shut until
    you commit.
  - NUMBERS (new, generated): relative vs absolute risk, points vs percentages,
    denominators, mean vs median, direction of a conditional, small samples.
    Absorbed the base-rate generators and Fermi prompts.
  - STEELMAN (new, written): build the strongest case FOR a proposition, with
    the lazy version named up front. data/propositions.json, 40 contested
    propositions. Third steelman day argues against the user's own position
    file. Third system prompt judges the construction, not the conclusion.
  - CALIBRATION: bank grown 70 -> 395 statements across 8 categories, split
    207/188 true to false. Drawn least-recently-seen first; unseen count shown.
  - Confidence now asked on logic and causal too, all feeding ONE curve tagged
    by source.
  - Logic/causal/numbers/calibration share one drill stage.
  - Old save files load unchanged.

  Bug found and fixed: first draft of the logic generators gave plural subjects
  singular verbs ("No glaziers signs the register"). Swept 4,800 items after
  fixing.

PHASE 7 — A session survives a reload                          [7f9be52] DONE
--------------------------------------------------------------------------------
  Reported: refreshing while on a session backed out to today and then produced
  a different passage.

  Worse than reported: the passage had already been marked as seen, so it was
  consumed, and everything written in that session was lost. Pull-to-refresh is
  easy to hit on a phone and iOS discards backgrounded tabs on its own.

  - A session in progress is written to its own key (thinking-app:live) on
    every meaningful change, including the half-typed contents of the box.
  - On load it resumes: same passage, same question, same unfinished sentence,
    same reading or writing phase, timer measured from the original start with
    the arc still proportional to the whole session.
  - Drill days resume on a fresh item, since anything answered was already
    banked and re-showing it would count twice.
  - Cleared on close, abandon, import and erase. Ignored after 12 hours.
    Corrupt data falls back to a normal start rather than failing to boot.
